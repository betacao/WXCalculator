# 图标资源说明

## TabBar 图标要求

请在此目录下放置以下图标文件：

### 计算器图标
- `calculator.png` - 未选中状态（灰色）
- `calculator-active.png` - 选中状态（绿色 #4fc08d）

### 个人中心图标
- `profile.png` - 未选中状态（灰色）
- `profile-active.png` - 选中状态（绿色 #4fc08d）

### 登录页图标
- `login.png` - 登录页面展示图标

## 图标规格

- **尺寸**: 81px × 81px（推荐）
- **格式**: PNG 格式
- **背景**: 透明背景
- **设计**: 简洁扁平化风格

## 快速获取图标

可以从以下途径获取图标：
1. [iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
2. [iconpark](https://iconpark.oceanengine.com/) - 字节跳动图标库
3. 使用在线工具生成简单图标

## 临时方案

如果暂时没有图标，可以：
1. 使用纯色方块作为占位图标
2. 或者暂时注释掉 app.json 中的 tabBar 配置
